# RemoteFamily Milestone 0.1.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create a minimal RemoteFamily Android application that GitHub Actions tests, lints, assembles, and publishes as an installable debug APK without an Android toolchain on the workstation.

**Architecture:** A single `android/app` module uses AGP built-in Kotlin and Jetpack Compose to render one screen. The complete Gradle Wrapper is versioned, and a SHA-pinned GitHub Actions workflow is the authoritative Android build environment. Pure application identity is isolated from the Activity so its behavior can be developed with a remote red-green TDD cycle.

**Tech Stack:** AGP 9.3.1, Gradle 9.5.0, built-in Kotlin 2.2.10, Compose Compiler plugin 2.2.10, Compose BOM 2026.06.00, Activity Compose 1.13.0, Core KTX 1.17.0, JDK 17, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-08-26-milestone-0.1.0-design.md`

## Global Constraints

- Work only on Milestone 0.1.0; do not create server, WebRTC, MediaProjection, AccessibilityService, signaling, TURN, permissions, navigation, or future-milestone placeholders.
- Use `applicationId = "com.remotefamily.app"` and `namespace = "com.remotefamily.app"`.
- Use AGP `9.3.1`, Gradle Wrapper `9.5.0`, built-in Kotlin `2.2.10`, Compose Compiler plugin `2.2.10`, Compose BOM `2026.06.00`, Activity Compose `1.13.0`, Core KTX `1.17.0`, and JDK `17`.
- Use `compileSdk = 36`, `targetSdk = 36`, and `minSdk = 24`.
- Do not apply `org.jetbrains.kotlin.android`; AGP 9.3.1 provides built-in Kotlin.
- Do not use dynamic dependency versions, a version catalog, convention plugins, Android Studio, a local Android SDK, a local emulator, globally installed Gradle, or globally installed Kotlin.
- The Gradle Wrapper distribution and wrapper JAR checksums must be verified.
- All GitHub Actions must be pinned to immutable commit SHAs.
- A failing CI run is evidence for TDD or diagnosis, never milestone completion.
- Execute implementation on `codex/milestone-0.1.0` in an isolated worktree; never push the intentional red TDD commit to `main`.
- Do not declare the milestone complete until CI is green and the APK has been installed and opened on a physical Android device.

### Task 3: Add SHA-pinned Android CI

**Files:**
- Create: `.github/workflows/android-ci.yml`

**Interfaces:**
- Consumes: `android/gradlew` and Gradle tasks produced by Task 2.
- Produces: authoritative remote build checks, failure reports, and the `remote-family-debug` artifact used by Tasks 4 and 5.

- [ ] **Step 1: Create the workflow with immutable action revisions**

Create `.github/workflows/android-ci.yml`:

```yaml
name: Android CI

on:
  push:
    branches: [main]
    paths:
      - "android/**"
      - ".github/workflows/android-ci.yml"
  pull_request:
    paths:
      - "android/**"
      - ".github/workflows/android-ci.yml"
  workflow_dispatch:

permissions:
  contents: read

jobs:
  build:
    runs-on: ubuntu-latest
    timeout-minutes: 30

    defaults:
      run:
        working-directory: android

    steps:
      - name: Checkout
        uses: actions/checkout@d23441a48e516b6c34aea4fa41551a30e30af803 # v6

      - name: Setup Java
        uses: actions/setup-java@b6effb05e454b25005698d916606bdc6ffcbf961 # v5
        with:
          distribution: temurin
          java-version: "17"

      - name: Setup Gradle
        uses: gradle/actions/setup-gradle@4733eaac7c1b0da527e4206b7671e0061de1ce37 # v6

      - name: Make Gradle executable
        run: chmod +x gradlew

      - name: Unit tests
        run: ./gradlew testDebugUnitTest --stacktrace

      - name: Lint
        run: ./gradlew lintDebug --stacktrace

      - name: Assemble debug APK
        run: ./gradlew assembleDebug --stacktrace

      - name: Upload failure reports
        if: failure()
        uses: actions/upload-artifact@ea165f8d65b6e75b540449e92b4886f43607fa02 # v4
        with:
          name: android-build-reports-${{ github.run_id }}
          if-no-files-found: ignore
          path: |
            android/app/build/reports/
            android/app/build/test-results/

      - name: Upload debug APK
        uses: actions/upload-artifact@ea165f8d65b6e75b540449e92b4886f43607fa02 # v4
        with:
          name: remote-family-debug
          if-no-files-found: error
          path: android/app/build/outputs/apk/debug/app-debug.apk
```
